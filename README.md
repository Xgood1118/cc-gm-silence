# 静音检测

基于能量的静音检测器，只用 Python 标准库。

## 原理

1. **分帧**：50ms 窗口、10ms 步长计算每帧 RMS（`frame_rms`）。
2. **平滑**：对相邻 5 帧的 RMS 取**中值**。中值滤波能去掉个别帧的能量
   毛刺和说话中段的短暂音量跌落（说话段不会被误判成静音），同时不像
   均值滤波那样把段的边缘拖宽。
3. **合并**：连续低于阈值的帧合并为一段候选静音，因此 0.6 秒的静音
   输出为一段，而不是十几个窗口条目。
4. **过滤**：丢弃短于 `min_silence_ms` 的候选段。
5. **边界修正**：在粗边界附近以 1ms 步长用 10ms 探针窗口重新扫描能量
   越过阈值的位置，起止误差控制在 10 毫秒以内；最后把边界钳制在
   `[0, 音频时长]` 内，不会越界。

## 阈值

阈值按 RMS 绝对值判定，通过 `--threshold` 配置（默认 200）。判定作用在
中值平滑后的帧能量上，所以单个窗的能量抖动不会引起误判；`--min-ms`
控制多短的静音被忽略。

## 过零率

`zero_crossings(samples, start, length)` 严格统计 `[start, start+length)`
区间内的过零次数。报告里每段都带 `zero_crossing_rate`（次/秒）：浊音
（元音、周期信号）过零率低，清音（摩擦音等类噪声）过零率通常高出一个
数量级，静音段为 0，可直接从报告中区分。

## 运行

```
python gen_samples.py
python -m silence.cli data/speech.wav --threshold 200 --min-ms 200 --out silence.json
python -m pytest tests -q
```

`speech.wav` 16k 单声道 1.88 秒，结构是：说话 0.4 秒、静音 0.6 秒、说话
0.3 秒、极短停顿 0.08 秒、说话 0.5 秒。

## 实测结果

`python -m silence.cli data/speech.wav --threshold 200 --min-ms 200 --out silence.json`
共检出 **1 段静音**：

| 段 | 起点 | 终点 | 时长 | 平均能量 | 过零率 |
|---|---|---|---|---|---|
| 静音 1 | 400.0ms | 1000.0ms | 600.0ms | 0.00 | 0.0/s |

说话段（报告的 `speech_segments`，用于对照过零率）：

| 段 | 起点 | 终点 | 时长 | 平均能量 | 过零率 |
|---|---|---|---|---|---|
| 说话 1 | 0.0ms | 400.0ms | 400.0ms | 6363.58 | 597.5/s |
| 说话 2 | 1000.0ms | 1300.0ms | 300.0ms | 6363.52 | 836.7/s |
| 说话 3 | 1380.0ms | 1880.0ms | 500.0ms | 6363.52 | 518.0/s |

起止与真实边界（400ms / 1000ms）完全重合，误差为 0，远小于 10 毫秒的
要求。三段说话的过零率（约 520–840/s）随基频不同而明显区分，且都远
高于静音段的 0/s。

### 为什么 0.08 秒那段没出现

1300–1380ms 的停顿只有 80ms，虽然它确实被帧分类判为静音并合并成了
候选段，但 `--min-ms 200` 要求静音段至少 200ms，80ms < 200ms，在过滤
阶段被丢弃。它仍作为说话段 2 与说话段 3 的分界体现在报告中。
