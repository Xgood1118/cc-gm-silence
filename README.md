# 静音检测

骨架能算窗口能量、能列出低于阈值的窗口，但结果既碎又不准。

## 已知缺口

- 窗口固定 50 毫秒且不重叠，静音段的起点边界最多差 50 毫秒。
- 相邻的静音窗口不合并，一段 0.6 秒的静音会被拆成十几个条目。
- 没有按 `min_silence_ms` 过滤，0.08 秒的短暂停顿也会被算成一段静音。
- 阈值只按绝对 RMS，音量正常的说话段在中段也可能掉到阈值以下，出现假阳性。
- `zero_crossings` 忽略 `start` 参数，总是从数组开头数，用来判断清音与浊音时结果无意义。
- 结束边界按窗口末尾算，最后一个窗口超出数组长度时时间戳被截断。

## 运行

```
python gen_samples.py
python -m silence.cli data/speech.wav --threshold 200 --min-ms 200 --out silence.json
python -m pytest tests -q
```

`speech.wav` 16k 单声道 1.88 秒，结构是：说话 0.4 秒、静音 0.6 秒、说话 0.3 秒、
极短停顿 0.08 秒、说话 0.5 秒。
